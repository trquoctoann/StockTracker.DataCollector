# Contributing

Follow [AGENTS.md](AGENTS.md) for coding conventions and validation commands. The same rules apply to human and agent contributions. Read docs/provider-contract.md before changing identifiers, timestamps, units or mappings.

Update owning documentation alongside behavior changes. Review [outstanding findings](docs/review.md) so defects are not copied into new code. Explain observable behavior, contract/database compatibility, tests run, and checks that could not run.

Maintained code and documentation use English ASCII text. Provider fixture strings may use Unicode escapes. Do not put credentials, access tokens or request passwords in examples or logs.
